# Project Management

## Approach

This project was built iteratively rather than against a fixed
upfront plan. Work was split by domain: Morgane led the visual
side (UI, rendering, neon effects, ghost sprites, menu flow),
while Léo led the game logic, security/robustness, and tooling
(Makefile, linting, type checking).

Progress was tracked informally, feature by feature, with each
addition (collision, pathfinding, difficulty scaling, countdown
system...) implemented, tested in-game, and refined before moving
to the next.
